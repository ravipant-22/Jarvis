JARVIS – Python Voice Assistant
JARVIS is a Python-based voice assistant designed to perform everyday tasks through voice commands. The project uses speech recognition to capture and understand the user's voice, allowing the assistant to respond and perform actions without requiring manual input.
The assistant continuously listens for the wake word "Jarvis". Once the wake word is detected, it becomes active and listens for the user's command. Based on the command, JARVIS can perform predefined tasks such as opening Google, YouTube, Facebook, and LinkedIn. It can also play songs from a predefined music library when the user gives a music-related command.
The project also integrates NewsAPI to provide the latest news headlines. When the user asks for news, JARVIS retrieves the available headlines and reads them aloud using its text-to-speech functionality.
For commands that are not handled by the predefined functions, JARVIS uses the OpenAI API to generate an intelligent response. This allows the assistant to handle general questions and conversations instead of being limited to a fixed set of commands.
For voice output, the project uses gTTS (Google Text-to-Speech) to convert generated text into speech and Pygame to play the resulting audio. The project also includes pyttsx3 as an alternative text-to-speech engine.
The main technologies and libraries used in this project include Python, SpeechRecognition, PyAudio, gTTS, Pygame, pyttsx3, OpenAI API, NewsAPI, Requests, Web Browser, and a custom music library.
The project demonstrates the practical use of voice recognition, artificial intelligence, APIs, text-to-speech, web automation, and Python programming to create an interactive virtual assistant. It can be further extended with features such as weather updates, reminders, alarms, system controls, application launching, improved conversational capabilities, and more advanced voice recognition.
